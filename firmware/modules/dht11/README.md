# DHT11 模块

来源：`模块代码/DHT11/DHT11/`（较新的版本，包含位对齐修正和校验和）。

## 文件

- `dht11.c` / `dht11.h`
- `DHT11.ioc`（CubeMX 引脚/时钟配置参考）

## 接线

```text
VCC  -> 3.3V
GND  -> GND
DATA -> PC1（示例），4.7k–10k 上拉到 3.3V
```

## 集成要点

1. CubeMX 里把 DATA 引脚的用户标签命名为 `DATA`，生成 `DATA_Pin` / `DATA_GPIO_Port`。
2. `dht11.c` 使用 DWT->CYCCNT 做微秒延时，不额外占定时器。
3. 读取 40 bit 时会短暂关中断，保证时序；不要在中断里调用。
4. 采样间隔 ≥ 2 s；`0x301` 每 500 ms 发送缓存值。
5. 校验和 = 前 4 字节相加取低 8 位；失败返回 0，调用方要计数并接 DTC。

## 已知问题

- `HAL_Delay(20)` 是阻塞的；在 FreeRTOS 里应放在独立传感器任务，不要放高优先级任务。
- 如果 DHT11 和 PIR 都用 PC1，会冲突；本项目 PIR 默认改到 PE0。
